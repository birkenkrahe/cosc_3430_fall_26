  instance/row/observation comes with the expected output, the
  district's median house prices -> *supervised ML*

** [Slides 11–14] How would you measure the model's performance?
*** [Slide 11] RMSE

- We need a metric to evaluate the model's performance, also called a
  loss or cost function.

- For regression problems, we use RMSE (*Root Mean Squared Error*):
  #+attr_html: :width 400px :float nil:
  [[../img/rmse.png]]

  Where:
  + m ("sample") is the number of instances (rows/observations),
    i = 1..m
  + x^{(i)} ("features") is the i-th vector of all feature values
    except the label (if there are 10 features, then its length is 10)
  + h(x^{(i)}) ("hypothesis") is the model prediction for instance i
    (a single number, not a vector)
  + y^{(i)} ("target") is the actual label for instance i
  + *X* is a matrix with all feature values (except labels) of all
    instances: One row per instance, the i-th row is equal to the
    transpose of x^{(i)}, x^{(i)T}

- RMSE code example:
  #+begin_src python :results output :exports both :session *Python* :python python3
    import numpy as np  # import library for data frames
    import pandas as pd  # import library for numerical functions

    # Five districts: feature vectors x^(i) (one row each = the matrix X)
    X = pd.DataFrame({
        "longitude":         [-122.23, -118.41, -117.05, -121.32, -119.78],
        "latitude":          [  37.88,   34.02,   32.91,   38.44,   36.21],
        "housing_median_age":[  41,      25,      35,      18,      30  ],
        "total_rooms":       [  880,    7099,    1274,    1627,    2519  ],
        "population":        [  322,    2401,     570,     595,    1049  ],
        "median_income":     [  8.30,    3.21,    4.58,    2.94,    5.12  ],
    })
    # print the sample data frame (puts it in a string - no truncation)
    print(pd.DataFrame(X).to_string(index=False))

    # what median house value labels might be
    actual    = np.array([156_400, 230_000, 185_000, 310_000,  97_500])  # labels y^(i)
    # what a model's predictions might be
    predicted = np.array([148_000, 241_000, 179_500, 325_000, 112_000])  # h(x^(i))
    # compute root mean square error on the data and print it
    rmse = np.sqrt(np.mean((predicted - actual) ** 2))
    print(f"\nRMSE: ${rmse:,.0f}")
  #+end_src

*** [Slides 13–14] Why use RMSE? What is common to all performance measures?

- Why use RMSE?
  #+begin_quote
  The code example shows it: RMSE is in the same units as the target
  variable, which makes it more easily interpretable.
  #+end_quote

- What is common to all performance measures?
  #+begin_quote
  All performance measures are functions of the feature matrix *X* and
  the model (hypothesis h): they aggregate the difference between
  predictions h(x^{(i)}) and actual labels y^{(i)} into a single
  scalar. The choice between them (RMSE, MAE, etc.) depends on how you
  want to weight errors — RMSE penalizes outliers more heavily
  (quadratic), MAE treats all errors equally (linear absolute value).
  #+end_quote

* Glossary

| Term                  | Definition                                           |
|-----------------------+------------------------------------------------------|
| batch learning        | train on the whole static dataset at once, then      |
|                       | launch (vs. online learning, which updates           |
|                       | continuously).                                       |
| district              | a group of nearby households in the census data      |
|                       | (like a neighborhood or block group).                |
| feature               | one input column (predictor) used to predict the     |
|                       | label, e.g. median_income.                           |
| feature matrix (X)    | all feature values for all instances - one row per   |
|                       | instance, one column per feature.                    |
| hypothesis (h)        | the model's prediction function; h(x) is its         |
|                       | predicted value for input x.                         |
| label                 | the target value to predict, e.g.                    |
|                       | median_house_value.                                  |
| loss (cost) function  | a function that scores how far predictions are from  |
|                       | the actual labels, e.g. RMSE or MAE.                 |
| MAE                   | Mean Absolute Error - average of the absolute        |
|                       | prediction errors; weighs every error equally        |
|                       | (linear).                                            |
| online learning       | update the model continuously as new data arrive     |
|                       | (vs. batch learning, which trains once).             |
| pipeline              | the sequence of steps from framing the problem to    |
|                       | monitoring a deployed model.                         |
| regression            | predicting one continuous numeric target             |
|                       | (univariate) from several predictors (multiple).     |
| RMSE                  | Root Mean Squared Error - square root of the mean    |
|                       | squared error; same units as the target, penalizes   |
|                       | large errors more than MAE.                          |
| supervised learning   | training with labeled examples, each input paired    |
|                       | with its correct target output.                      |
