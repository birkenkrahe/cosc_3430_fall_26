* Understand what this course is about

- This is what the catalog says:
  #+begin_quote
  "This course introduces the student to various aspects of artificial
  intelligence (AI), whose goals are the creation of more useful
  machines by making them more "intelligent." The course focuses on
  the *fundamentals* of machine learning (ML) and uses supervised,
  unsupervised, and reinforcement learning *algorithms* for
  *classification* and *prediction* tasks. The student will learn to build
  models from data using *regression*, logistic regression,
  classification and regression *trees*, random forests, ensemble and
  boosted methods, neural network techniques, and *deep learning* using
  convolutional *neural networks* (CNN). These algorithms are then
  applied to the areas of machine vision, image feature *recognition*,
  *natural language processing* (NLP), and general predictive techniques
  used in the field of *Data Science*."
  #+end_quote

- Prerequisites: COSC 2230 or COSC 1300
  #+begin_quote
  COSC 2230 (CS III): You can write programs that don't just
  work, but scale, perform, and hold up under real-world conditions,
  using OOP design, generic functions, concurrency, core data
  structures and algorithms. Usually taught with Java.

  COSC 1300 (Intro to DS): Know tools to extract knowledge from data,
  manipulate, model and visualize data using Python and/or R.
  #+end_quote

- What this (probably) means:
  #+begin_quote
  You can write solid programs for a wide variety of tasks, or you
  already know how to wrangle and visualize data (in Python or R).

  Now you'll teach the computer to find patterns on its own. You'll
  build models that predict house prices from its features, sort
  emails into spam or ham, group similar customers automatically,
  recognize a cat in a photo, or analysing tweets for feelings.
  #+end_quote

- This is what the course is really about:
  #+begin_quote
  1. Learn how to teach a machine from examples instead of rules.
  2. Learn the algorithms — from simple regression to deep neural
     networks — that make this learning possible.
  3. Learn to apply these algorithms to real problems: seeing,
     reading, and predicting.
  #+end_quote

* Find out about the project
#+attr_html: :width 400px :float nil:
[[../img/scrum.jpg]]

- Scrum = agile method (software engineering)

- 4 sprint reviews (prototype presentation):
  + Sprint 1: Project Proposal (What do you want to do?)
  + Sprint 2: Literature Review/Method (How are you going to do it?)
  + Sprint 3: Results/MVP (What did you do)
  + Sprint 4: Discussion/Presentation (Why is it interesting)

- Alignment with IMRaD:
  1. Introduction
  2. Method
  3. Results and
  4. Discussion

- Two tracks: Coding or Concept

- Topic ideas for a *coding* (building) project:
  1. Regression project: predict a real number
  2. Classification on a small dataset
  3. Image-classifier for a Non-MNIST image dataset
  4. Decision tree vs random forest on tabular data
  5. Ensembles: voting vs. bagging vs. boosting
  6. K-means color segmentation tool
  7. Dimensionality reduction visualizer
  8. Semi-supervised labeling (with clustering)
  9. From Scikit-Learn MLP to PyTorch MLP
  10. Shallo CNN vs. deep regularized CNN

- Topic ideas for a *concept* (explaining) project:
  1. The ML landscape
  2. The ML workflow
  3. Classification metrics
  4. Gradient descent
  5. Decision trees and ensembles
  6. Dimensionality reduction
  7. Clustering
  8. Artificial Neural Networks
  9. Deep computer vision
  10. Transformers and LLMs

- *AI Use Policy:* AI tools are welcome for research, debugging, and
  drafting, but every line of code you submit for Sprint 3 (results)
  must be code your team understands and can explain live; disclosed
  use is fine, undisclosed or unexamined AI-written MVPs are not.

| Data visualization | Representing data graphically to reveal patterns |
